# 🍓 Strawberry Pomodoro Timer

A cute, aesthetic, and functional Pomodoro timer designed to help you stay focused while tracking your progress with style. 

![Strawberry Icon](public/strawberry-favicon.png)

## ✨ Features

- **🍓 Aesthetic Timer**: A squishy, dancing strawberry mascot that cheers you on while you work!
- **📊 Progress Heatmap**: A GitHub-style contribution graph that tracks your daily Pomodoro completions over the last 12 weeks.
- **📈 Detailed Stats**: Track your total cycles, current streaks, and all-time best streaks.
- **🌙 Dark & Light Mode**: Seamlessly switch between a soft cream theme and a deep berry dark mode.
- **✨ Interactive Background**: petite handmade stars that react to your mouse movements.
- **📱 Responsive Design**: Fully optimized for mobile, tablet, and desktop viewing.
- **💾 Local Persistence**: Your progress data and settings are saved automatically to your browser's localStorage.
- **🚀 PWA Support**: Install it on your device for a native-like app experience.

## 🚀 Getting Started

### Prerequisites
- [Node.js](https://nodejs.org/) (v20.19+ or v22.12+ recommended for Vite 7)
- [npm](https://www.npmjs.com/)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/misscoder51/strawberry-pomodoro.git
   cd strawberry-pomodoro
   ```

2. Install dependencies:
   ```bash
   npm install
   ```

3. Start the development server:
   ```bash
   npm run dev
   ```

## 🛠️ Tech Stack

- **Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite 7](https://vitejs.dev/)
- **Styling**: Vanilla CSS with Modern Glassmorphism
- **Persistence**: Browser LocalStorage API
- **PWA**: [Vite PWA Plugin](https://vite-pwa-org.netlify.app/)
- **Deployment**: GitHub Pages

## 📖 How to Use

1. **Set your intervals**: Customize your work, short break, and long break durations in the settings.
2. **Start the timer**: Click "start focus" and let the strawberry mascot keep you company.
3. **Complete cycles**: Every time a work period ends, your progress is automatically saved.
4. **Check your progress**: Click the 📊 icon in the top-left corner to see your activity heatmap and streaks!
